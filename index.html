📌 திட்டத்தைப் பற்றிய வழிகாட்டி (About & How to Use)

இந்த அமைப்பானது ஓட்டுநரின் கவனச்சிதறல், தூக்கக் கலக்கம் மற்றும் கொட்டாவி விடுதல் போன்றவற்றை நிகழ்நேரத்தில் (Real-time) கண்காணித்து எச்சரிப்பதற்காக உருவாக்கப்பட்டது.

பயன்படுத்தும் முறை: கீழே கொடுக்கப்பட்டுள்ள பெட்டியில் உங்களது Telegram Chat ID-ஐ மட்டும் உள்ளிட்டு Start Monitoring கொடுக்கவும். (Chat ID எடுக்கும் வழிமுறைகள் கீழே கொடுக்கப்பட்டுள்ளன).

  • 😴 தூக்கக் கலக்கம் (Drowsiness): கண் மூடினால் குரல் எச்சரிக்கையுடன் (Audio Warning) டெலிகிராமிற்கு மெசேஜ் வரும்.
  • 🥱 கொட்டாவி (Yawning): சோர்வாகி கொட்டாவி விட்டால் உடனடியாகக் கண்டறிந்து எச்சரிக்கும்.
  • 🚨 விபத்து எச்சரிக்கை (Accident SOS): விபத்து நிகழும் சூழலில் நேரலை இருப்பிடத்துடன் (Live GPS Location) அவசரச் செய்தி அனுப்பப்படும்.

📌 Telegram Chat ID எவ்வாறு பெறுவது? (Guide)
  1. Telegram ஆப் ஓபன் செய்து @userinfobot என தேடவும் (Search).
  2. அந்த பாட் (Bot)-ஐ ஓபன் செய்து /start கொடுக்கவும்.
  3. உடனடியாக உங்களின் Id (எடுத்துக்காட்டாக: 123456789) திரையில் தோன்றும்.
  4. அந்த ID-ஐ மட்டும் கீழே உள்ள பாக் ஸில் உள்ளீடு செய்து Save Chat ID கிளிக் செய்யவும்.
